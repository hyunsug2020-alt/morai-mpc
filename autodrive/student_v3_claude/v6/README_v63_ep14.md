# v6.3 판단 모델 (epoch 14/30, 중간 테스트용) — 가상 장애물 학습 반영

**중간 결과물**이에요. 학습은 계속 돌고 있고(10/9 저녁 종료), 최종본은 따로 올려요.
이 모델은 v6.2 패키지(`v6/lane_map.py` 포함)와 **그대로 호환**돼요. 패키지(`patch/`)는 v6.2 때와 동일하고, 모델 파일만 바꾸면 돼요.

## v6.2와 달라진 점 (장애물 반응 문제 대응)
- 지난 테스트에서 v6.2는 장애물 쪽으로 피하거나 안 피하는 경우가 많았어요. 가상 장애물 시험으로 재현해 보니 **장애물 위치를 거의 안 보고** 도로 모양으로 찍고 있었어요 (막는 장애물 정답 34%).
- v6.3은 학습 샘플의 20%를 **가상 장애물 장면**으로 채웠어요: 빈 도로 장면(3개 카메라 4프레임)에 실제 시맨틱에서 오려 낸 드럼통·콘·박스 모양을 지면 위치에 맞게 그려 넣고, 정답은 플래너 습관을 정리한 규칙(`avoid_policy.py` 동봉)으로 줘요.
  - 오른쪽에 같은 방향 차로가 있으면 → 오른쪽
  - 1차로 도로(왼쪽이 반대 차선) → 왼쪽
  - 차로 안에서 조금만 비키면 되면 → 오른쪽 조금
  - 양쪽 다 안 되면 정답 없음(학습 제외)
- 회피 시작 시점을 앞당긴 정답 400개 추가(장애물이 보이는 시점부터).

## 알아 둘 것
- 양쪽 다 차로가 있는 도로에서 장애물이 가운데/오른쪽이면 약 30%는 **왼쪽**으로 피하라고 해요(플래너 습관은 오른쪽). 양쪽 다 주행 가능 차로라 위험 방향은 아니지만 플래너와 다를 수 있어요.
- 장애물이 막힘 경계(내 차 옆 1.6 m 정도)에 걸쳐 있으면 회피/직진이 갈려요. 그 구간은 학습에서 정답을 주지 않은 애매 구간이에요.
- 회피 방향 정답 정의(채점 때 동일하게): 앞 3~40 m, 경로 기준 |옆거리| < 0.95 + 물체 반지름 + 0.3 m 인 가장 가까운 장애물. 옆에 있거나 지나가는 장애물은 기준이 아니에요.
- 장애물이 확인되지 않았을 때 v6 단독 차로 변경은 막아 두세요. STOP/YIELD는 별도 로직이 담당해요.
- HD맵 정제 파일 필수(v6.2와 동일): `autodrive/ws/src/moraimpc/data/competition_directional_drivable_map.json.gz` (+ `local_bypass_corridor_overrides.json` 있으면 사용). 다른 위치면 `STUDENT_V6_LANE_MAP`, `STUDENT_V6_LANE_CORRIDORS`.

## 설치 (주행 PC, 회차 사이에)
v6.2 패키지가 이미 설치돼 있으면 **모델 파일만** 바꾸면 돼요:
```
cd morai_competition
cp <이 폴더>/v6_model.pt autodrive/student_v3/v6_model.pt     # 또는 STUDENT_V6_CHECKPOINT 로 지정
cd autodrive/student_v3 && $STUDENT_PYTHON -m unittest test_v6_shadow
```
v6.1 이하이거나 처음이면 v6.2 README와 같아요 (`patch/`, `v6_shadow.diff`, `v6_shadow.bundle` 동봉, gui.py는 v6.1부터 동일).
