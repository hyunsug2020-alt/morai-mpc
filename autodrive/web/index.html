Teacher 검사: 회색=route · 초록=실제 주행 · 빨강=Teacher 예측
3

데이터 검증 (prepare)

source.jsonl 전체를 Student 학습 형식으로 변환하며 timestamp 정합·라벨 유효성·세션 단위 train/val 분리를 검사. synthetic 0, 샘플 수와 supervision 개수가 결과에 나온다.

4

학습

시험 학습은 GPU 1에서 몇 step만 돌려 loss가 내려가는지 확인(세션 2개 이상 필요 — val 세션이 있어야 함; Teacher 풀이 GPU 1을 쓰면 먼저 stop-teacher-pool.sh). 전체 학습은 Teacher 전부를 내리고 4×4090 DDP로 실행.

학습된 Student를 2단계에서 선택한 세션 clip에 돌려 Teacher 라벨·실제 주행과 비교 (action 일치율, ADE/FDE, 지연). best.pt는 val loss 최저 epoch라 val 세션이 작거나 다르면 epoch 0(미학습)이 뽑힐 수 있음 → 보통 last.pt로 확인.

Student 검사: 회색=route · 초록=실제 · 빨강=Teacher · 파랑=Student
